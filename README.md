# Beyond the log transformation: Tweedie GLMM masterclass

Slides and R script from a postgraduate taught methods masterclass,
School of Health and Wellbeing, University of Glasgow, 8 May 2026.

- Slides: Slides_Tweedie_Masterclass.pdf
- Script: Tweedie_Masterclass_Script.R

The synthetic dataset used in the live session is not included. It was
generated from the Scottish Health Survey 2017, which the UK Data Service
distributes under its End User Licence, and datasets derived from it,
including synthetic ones, cannot be shared publicly.

To run the script, register with the UK Data Service and download the
Scottish Health Survey, 2017 (SN 8398, https://doi.org/10.5255/UKDA-SN-8398-1).
Variable names follow that release (for example, drating for usual weekly
alcohol units); check them against your copy.
